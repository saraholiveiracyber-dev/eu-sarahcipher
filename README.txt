CASA, CAFÉ & CONTEÚDO — SITE SARAH OLIVEIRA

Estrutura:
index.html       página inicial
orcamento.html   página de orçamento
style.css        estilos do site
orcamento.css    estilos do orçamento
script.js        menu, animações e ano automático
orcamento.js     validação do formulário
img/             capas do e-book

COMO USAR:
1. Abra a pasta no Visual Studio Code.
2. Abra o index.html com Live Server.
3. Coloque as capas reais em img/capa-ebook.png e img/capa-ebook1.png.
4. Para o Instagram, confira o endereço no HTML antes de publicar.
5. O formulário é visual/validado no navegador; para receber respostas, conecte-o a um serviço de formulários, e-mail, WhatsApp ou backend.
